Closed vs Open Loop Object Pushing

Random-object pushing (rl_push): 5 test objects drawn with default_rng(0), one goal each (goal t0 of the 5 x 5 draw: uniform over a 5 to 15 cm annulus around the object's frame-0 centroid, default_rng(0); spec sweeps/rlpush_cl_5.json, reduced from 25 problems at the user's request). Checkpoint pwm_v1_rl_push_ctxgen_100m_uncond_unet_bidir/step_180000.pt, the one used by this package's latest rl_push runs. Guidance as those runs: 4 members, 40 transitions, S 10, Adam lr 0.2 to 0.02, 10 iterations, full churn, upright weight 1, contact weight 2, seed 0. Every model call reads the full 19-row window (tail padded). Open loop: the first plan, all 40 hand frames executed. Closed loop: execute 10 frames in Isaac, feed back the last 3 executed transitions as clean context, replan the rest (at least 16 generated), reward on task frame 40. Scored in Isaac (floating Franka hand, the object's CoACD hulls): object centroid to goal at frame 40.
