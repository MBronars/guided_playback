Carton Over a Wall, Ground Target

Milk carton #0037 (benchmark episode), target = start + 30 cm x ON THE GROUND, 10 cm-high 30 cm-wide 2 cm-thick wall box midway (in the objective only: clearance term; the Isaac scene has NO wall). Population 4, Adam, S=10. Grouped by checkpoint; each entry = one settings variant (frames, iterations, lr, shell, wall weight / clearance margin). Planner-view result = the member with the lowest generated distance. Pickup-only: baseline 20 it shell -> pick m1 371 mm (never lifts); A 40 it lr .2 w20 -> m0 36 mm; B 30 it no shell w10 -> m0 16 mm; C 90 frames 20 it -> m0 44 mm (3 of 4 members land within 77 mm having cleared the wall). Two-domain 120k: baseline -> m1 5.7 mm; A -> m3 388 (never lifts); B -> m3 388 (never lifts); C 90 frames -> m2 12 mm (clearance 43 mm; m1 and m3 clip the wall box). Layers: generated plan, unguided plan, Isaac replay of the guided plan. Drag to orbit, scroll to zoom, shift-drag to pan. Pick a domain, a run (newest first), then a member; layers toggle below the viewer.

Method. Streaming rollout of N transitions from frame 0, every action hidden. Full churn (η = 1): each active row is re-formed from the model's x0 with a pre-decided draw x = x0 + l (E[row, i] − x0); the rollout is a deterministic function of the draw bank E. Guidance: J = ‖c_obj(x_N) − target‖ + w_box · clearance shortfall + w_floor · depth, gradient through every model call (activation-checkpointed), update of the free draws (level ≥ t_freeze) by Adam or a unit-gradient step, best (member, iteration) kept; iteration 0 = unguided. Simulated layer = the generated actuator trajectory played back in the domain's simulator (Isaac floating hand / Genesis MPM / SAPIEN PushBoundary), the object left to physics.
