Closed vs Open Loop Pushing

Five hard-set scenarios (seed 42; the paper's pushing video episodes). Same checkpoint (push0418_rigid_x0_rope_regpass_mix_cont200k_stream/final.pt, step 200k), same sampler (streaming staircase, full churn, every model call 3 + 26 rows, tail padded), same guidance (3 members, S 6, 6 iterations, lr 0.1, t_freeze 0.5, seed 0). Open loop: one 60-frame plan, all 60 rod actions executed. Closed loop, context 3: plan, execute 10 actions in SAPIEN, feed back the last 3 executed transitions as clean context, replan the remaining frames (at least 26 generated), reward always on task frame 60. Closed loop, context 0: the same, but each replan sees only the current executed frame as its anchor and generates its own context rows (as open loop does from frame 0). All executions are SAPIEN set-pose replays; the plan of the closed loop's first replan equals the open-loop plan.

Drag to orbit, scroll to zoom, right-drag to pan. Clouds are the scenario's frame-0 generated cube (128 points) and rod (128 points); executed clouds are those points under the simulated block pose and rod position.
