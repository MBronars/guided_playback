Pickup-only checkpoint, the 25-pick benchmark (target = start + (dx, dy, +15 cm)). MPPI argmin (no gradients): each replan draws K=32 fresh samples of the remaining frames from the committed frames, keeps the one whose final object centroid is closest to the target, commits 5 frames; 12 replans, 190.4 +- 0.4 s per plan. All 25 picks, plus the guided planner's plan (Adam on the initial noise, shell on, lr 0.1, 10 it, pop 4) for the 7 picks where the MPPI plan loses the object in Isaac. For MPPI runs the 'guided' layer is the committed plan and 'unguided' is the first plain sample; 'simulated' = Isaac replay. Seams between committed segments at frames 5, 10, ..., 55. Isaac: object leaves the fingers at frame 29 (peanut butter jar t0), 43 (jar t3), 41 (soda can t1), 55 (can t3), 25 (can t4), 55 (water bottle t1); water bottle t3 never lifts. Pick a domain, a run (newest first), then a member; layers toggle below the viewer.

Method. Streaming rollout of N transitions from frame 0, every action hidden. Full churn (η = 1): each active row is re-formed from the model's x0 with a pre-decided draw x = x0 + l (E[row, i] − x0); the rollout is a deterministic function of the draw bank E. Guidance: J = ‖c_obj(x_N) − target‖ + w_box · clearance shortfall + w_floor · depth, gradient through every model call (activation-checkpointed), update of the free draws (level ≥ t_freeze) by Adam or a unit-gradient step, best (member, iteration) kept; iteration 0 = unguided. Simulated layer = the generated actuator trajectory played back in the domain's simulator (Isaac floating hand / Genesis MPM / SAPIEN PushBoundary), the object left to physics.
