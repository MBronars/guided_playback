Carton Over a Wall

Pickup-only checkpoint, milk carton #0037. Target = start + (+30 cm x, +15 cm z). 'Wall' run: a 10 cm-high, 30 cm-wide, 2 cm-thick wall box midway between start and target is in the objective (clearance term, 5 mm margin, weight 5); shell on, Adam lr 0.1, 20 iterations, 60 frames, S=10, population 4. The no-wall run is the earlier far30 case (same target, 10 iterations). 'simulated' = Isaac floating-hand replay; the Isaac scene has NO wall, the box is drawn from the objective. Wall run: generated 5.8/78.3/12.1/17.6 mm, Isaac 36/107/26/70 mm; min clearance to the wall box 24-93 mm (object and gripper, generated and replayed). Drag to orbit, scroll to zoom, shift-drag to pan. Pick a domain, a run (newest first), then a member; layers toggle below the viewer.

Method. Streaming rollout of N transitions from frame 0, every action hidden. Full churn (η = 1): each active row is re-formed from the model's x0 with a pre-decided draw x = x0 + l (E[row, i] − x0); the rollout is a deterministic function of the draw bank E. Guidance: J = ‖c_obj(x_N) − target‖ + w_box · clearance shortfall + w_floor · depth, gradient through every model call (activation-checkpointed), update of the free draws (level ≥ t_freeze) by Adam or a unit-gradient step, best (member, iteration) kept; iteration 0 = unguided. Simulated layer = the generated actuator trajectory played back in the domain's simulator (Isaac floating hand / Genesis MPM / SAPIEN PushBoundary), the object left to physics.
